Простой скрипт для автоматического обновления IPv4 и IPv6 адресов в DuckDNS через systemd таймеры.

## 🛠 Установка

Для установки скрипта выполните следующую команду от имени обычного пользователя (скрипт сам запросит пароль sudo):

```bash
wget -O install.sh https://raw.githubusercontent.com/Garykom/Scripts/main/duck_install.sh && sudo bash install.sh && rm install.sh
Что произойдет при запуске:
Установится зависимость curl.
Скрипт автоматически определит ваш WAN-интерфейс.
Вам будет предложено ввести ваш Домен и Токен DuckDNS.
Будет создан systemd-сервис и таймер (запуск каждые 15 минут).
⚙️ Управление и проверка
Проверить статус таймера:

bash
systemctl status duckdns.timer
Запустить обновление вручную прямо сейчас:

bash
sudo systemctl start duckdns.service
Посмотреть логи выполнения:

bash
journalctl -u duckdns.service
Изменить настройки (домен, токен или интерфейс):

bash
sudo nano /etc/duckdns.conf
После изменения конфига просто подождите следующего запуска таймера или запустите сервис вручную.

### Почему стоит делать именно так:
1.  **Блоки кода (```bash ... ```)**: В интерфейсе GitHub при наведении на такой блок появляется кнопка «Копировать», что очень удобно для пользователя.
2.  **Разделение на этапы**: Пользователь понимает, что от него потребуют ввести данные, и не пугается «черного ящика».
3.  **Команды управления**: Вы сразу даете инструменты для диагностики (`journalctl`, `systemctl`), что избавляет вас от лишних вопросов в Issues вашего репозитория.
